# 2027 우리들의 문학수업

세종시 양지고등학교 1학년을 위한 2022 개정 공통국어 문학 12차시 자료 프로젝트입니다.

교과서 목차는 사용자가 제공한 사진을 참고합니다. 교과서와 문학 작품의 저작권 보호 본문은 이 저장소에 복제하지 않습니다.

## 공개 자료

웹사이트: https://kate-young2026.github.io/2027-our-literature-class/

‘문학이란’ 기초 2차시와 성취기준별 수업 12차시, 총 14시간으로 구성합니다. 기초 차시별 학습자료·활동지·모둠자료와 기존 12차시 학습자료·활동지를 제공합니다. 학생용 합본과 교사용 지도서에 기초 2차시를 포함합니다. 교사용 지도서는 공개 자료이며 학생도 열람할 수 있습니다. 작품 전문은 정식 교과서나 도서관 자료를 이용해야 합니다. 세부 수업 상황에 맞춰 교사가 자료를 검토하고 조정할 수 있습니다.

## PDF 다시 만들기

한글 글꼴 `C:/Windows/Fonts/malgun.ttf`, ReportLab·pypdf가 설치된 Python과 Node.js를 이용하여 `python generate-workshops.py`를 먼저 실행한 다음 `python generate-pdfs.py`를 실행합니다. 수업 내용의 공통 원본은 `workshops.js`와 `lessons.js`입니다.

## 수업 편성

| 성취기준 | 시수 | 주제 |
| --- | --- | --- |
| 10공국1-05-01 | 2 | 문학 소통 |
| 10공국1-05-02 | 2 | 갈래별 형상화 |
| 10공국1-05-03 | 2 | 구성 요소와 맥락, 작품 생산 |
| 10공국2-05-01 | 3 | 충청 지역 문학과 문학사 |
| 10공국2-05-02 | 3 | 주체적 해석·평가와 문학 향유 |

성취기준은 중등교육과정 MCP의 2022 개정 자료와 경기도교육청 국어과 성취평가 자료를 참조합니다. 2026년 개정 고시 원문도 확인했으며, 교육과정 적용 및 학교 편성은 해당 연도의 공식 안내를 함께 확인해야 합니다.

## 검사와 배포

`node verify.mjs`로 차시 번호, 성취기준별 시수, PDF 파일과 페이지의 필수 요소를 확인하고, `node test-ui.mjs`로 모의 DOM의 차시 열기·닫기와 PDF 링크를 확인합니다. 현재 GitHub Pages는 `main` 브랜치에서 배포합니다. 차시 원본을 수정할 때에는 PDF를 다시 생성하고 검사를 실행한 뒤 변경 사항을 올립니다. 공개 배포 시 웹 자료와 교사용 답안이 모두 공개됩니다.
