# 2027 우리들의 문학수업

세종시 양지고등학교 1학년을 위한 2022 개정 공통국어 문학 12차시 자료 프로젝트입니다.

교과서 목차는 사용자가 제공한 사진을 참고합니다. 교과서와 문학 작품의 저작권 보호 본문은 이 저장소에 복제하지 않습니다.

## 제작 상태

정적 웹 초안에 12차시의 학습목표·개념·활동 질문과 PDF 다운로드를 추가했습니다. `index.html`을 브라우저에서 열어 확인할 수 있습니다. 차시별 학습자료·활동지와 학생용 합본·교사용 지도서 PDF 초안 26개를 생성했습니다. PDF 일부 페이지를 시각적으로 확인했으며 전체 페이지 검토, 수업 내용 보강, 브라우저 검증 및 배포는 아직 완료되지 않았습니다.

## PDF 다시 만들기

한글 글꼴 `C:/Windows/Fonts/malgun.ttf`와 ReportLab이 설치된 Python, Node.js를 이용하여 `python generate-pdfs.py`를 실행합니다. 수업 내용의 공통 원본은 `lessons.js`입니다.
